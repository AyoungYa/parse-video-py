## 修复微博视频"下载按钮 403 Forbidden"（parse-video-py）

- 复现：解析 `https://weibo.com/tv/show/1034:5353240812781616` 成功，下载按钮报 403（Tengine 错误页）。
- 根因：微博/新浪 CDN 防盗链 —— 仅放行「浏览器 UA + 平台站内 Referer」或「完全不带 UA 的请求」；
  携带第三方 Referer（含本页 `127.0.0.1:8000`、`example.com`）一律 403。
  前端模板原用 `referrerpolicy="no-referrer"`（去 Referer）+ 浏览器 UA = 必 403，纯前端无法修复。
- 修复（后端代理转发）：
  - `src/parse_video_py/utils.py`：新增 `_DOWNLOAD_REFERER_RULES`（微博/抖音/B站/快手/小红书的域名→Referer 规则）、
    `match_download_referer()`、`build_download_header_candidates()`（候选头按序重试：平台Referer+UA → 仅UA → 无伪装头）、
    `is_downloadable_url()`（仅 http/https，拒绝 localhost/内网，防 SSRF）。
  - `src/parse_video_py/web.py`：新增 `GET /video/download?url=&filename=`，httpx 流式转发，透传 Range/Content-Range/Accept-Ranges，
    传 filename 时返回 attachment（ASCII 兜底 + RFC 5987 中文名），不传则内联返回供 `<img>` 使用；全部候选失败回 502。
  - `templates/index.html`：新增 `proxyUrl()/safeFileBase()/mediaExt()`，下载封面/视频/音频/LivePhoto、图集 `<img>`、
    「下载全部图片」的 fetch 全部改走代理（原先 fetch 里设置 Referer/UA 是浏览器禁止头，静默失效）。
- 验证：进程内 ASGI 端到端（沙箱有出口代理，本地端口不可直连）—— 视频 Range 206 + `bytes 0-1023/19005322`，
  封面 200 image/jpeg（`ffd8ff`），内联无 attachment，SSRF 地址 400，对照组直连仍 403；
  整片 19,005,322 字节经代理与直连 md5 完全一致（`989376a4fd1843518841cad730b58169`）。
  测试 85 passed（新增 15 个用例），black/isort/flake8(max-line-length=88) 全过。
- 知识库同步：02_project_map.md（API 路由/核心模块）、03_core_flows.md（新增「下载代理转发」流程）、
  99_global_index.md（核心代码索引 + 任务表）、CHANGELOG.md（Unreleased）。

## 微博直链如何下载到本地（代码方式）

- 关键：必须带 `Referer: https://weibo.com/` + 浏览器 UA，否则 403。
- 已实测两种可行方式，产物 md5 一致（`989376a4fd1843518841cad730b58169`，19,005,322 bytes，h264 720x1280 + aac，时长 215.85s）：
  1. `httpx` + `utils.build_download_header_candidates()` 逐块流式落盘（复用项目 utils）；
  2. `GET /video/download?url=&filename=`（curl `-G --data-urlencode`）走服务端代理。
- 产物：`~/Downloads/parse-video-downloads/weibo_5353240812781616.mp4`。
- 重要：微博直链带 `Expires`/`ssig` 签名，**有效期约 1 小时**，过期必须重新解析拿新链接。
