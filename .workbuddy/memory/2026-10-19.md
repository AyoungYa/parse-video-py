### ★ verify.py 又修了两个 720P 新坑（手册坑 33/34）
1. **坑 33 — 水印贴边 → ROI 越界崩**：ROI = mask+60px 留白，水印右界 1249 →
   ROI 右边 =1290 > 1280 → `gray_at` 静默裁小图 → `mask_full` 与 d 维度不符 →
   `IndexError`。另 `frame_alignment` 中心探测区写死 1080P `(760,340,400,400)`，
   720P 上 `340+400=740>720` 越界报错。
   **修法**：main 里 `rx=clamp(rx,0,VW-W)`、`ry=clamp(ry,0,VH-H)`；`gray_at` 非换算
   路径加断言；`frame_alignment` 探测区按真实分辨率取中心 1/3；`excerpt_offset`
   兜底候选也改为按真实分辨率的右上角 1/4。
2. **坑 34 — ③ 高运动假警报**：打样片 ③ 报 7.72 ❌ 但 ① 只有 +0.4。
   根因：① 报 offset=0、② 报 +1，二者不一致 → ③ 用了错的 offset（错配一帧）；
   且该片 ROI 是快速运动区（**原片自己相邻帧在 mask 外差异就达 12.4**）。
   **判据**：测"噪声地板"（原片相邻帧 mask 外差异）+ **水印窗口外全画面差异**
   （正确偏移下 **~1.4**）→ 证明是尺子被放大，**不是真污染，别返工**。
   全片验收 ③ 回落到 **1.15**，进一步坐实。

### ★ 帧完整性硬核复核法（不做 -ss 搜索）
② 报跳变时，用 `ffmpeg -vf select=eq(n,<k>) -frames:v 1` **按绝对帧号**取帧直比：
本例 n=1600 的"窗口外全画面均值 = **0.02**"（逐像素几乎全等）→ 证明帧序 100% 完整，
② 的跳变纯属 `-ss` 寻址假象。**"帧号直比"是比 -ss 搜索更硬的判据。**

## 追加：痕迹修复（用户反馈"水印去掉了但看得见一块痕迹"）

### 问题定性
三项指标全绿（① 成片 +0.1、② 帧序完整、③ 区外 1.9），但**肉眼在暗场帧上能看到
右上角一块"雾面方块"**。→ 这是**指标的盲区**：① 量字形残留、③ 量区外改动，
**都不看修复区内部的纹理自然度**。

### 定量诊断（detail 层 σ）
```python
detail = gray - GaussianBlur(gray, sigma=1.2)   # 细节层
比值 = detail[mask].std() / detail[ring].std()  # 1.0 = 纹理完全匹配
```
实测 LaMa 成片 **median 0.69 / min 0.41**（修复区纹理只有周边的七成）。
极端例：48s 帧原片区 22.9 → LaMa **0.03**（抹成纯色），而周边 20.4。

**关键判别**：先看**周边环 σ**——若周边也 ≈0（纯黑场），LaMa 抹平是**正确的**，
不用修；只有"周边有纹理、修复区 σ 远低于它"才需要补。

### 解法：新增 skill 脚本 `texture_fix.py`
`~/.workbuddy/skills/video-watermark-removal/scripts/texture_fix.py`（约 250 行）
- 原理：取 mask **外环**的真实细节层，**分块平铺（--tile 48）** 到修复区，
  归一化到 `target = σ_ring * strength`，再用羽化权重（GaussianBlur σ=2）叠加。
- 用法（★ 已加 `--audio-from` 一键混音，`--x/--roi-x` 同义）：
  ```bash
  python texture_fix.py 成片.mp4 --roi-x 930 --roi-y 10 \
      --mask-file mask_720p_wide.png --strength 1.3 --tile 48 \
      --audio-from 原片.mp4 --out 最终成片.mp4
  ```
- **实测效果**：mask 内/外 σ 比 **median 0.69 → 0.98 / mean 0.85 → 1.12 / min 0.41 → 0.72**；
  痕迹肉眼消失，① 仍 +0.1 ✅。
- 速度：1648 帧全片 **~56s**（2 核并行）。

### ★ 参数调优的两个失败教训（已写入手册坑 35）
1. **必须"分块平铺真实细节层"**——逐像素随机采样产生的是**不相关白噪声**，
   会被后续编码/放大毁掉（前两版效果 0.62→0.64，等于没加）。
2. **归一化到 `target = σ_ring`**，不是 `σ_ring - σ_in`（只补"亏空"太弱，
   再被羽化吃掉一半）。默认 `--strength 1.3`（1.0 偏弱 / 1.6 偏糙）。

## ★★★ 追加（本轮最大教训）：补纹理自测的「实心矩形口径陷阱」

**这是绕了整整 4 轮才走出来的坑，务必记住。**

### 症状
`texture_fix.py` 工作正常，但自测脚本查"修复区/周边 detail-σ 比"总是只有 **0.5~0.6**，
远低于 0.85 合格线 → 误判"补得不够" → **连续改了 4 版都更差**：
1. 自适应反解（方差域 `√(target²-σ_in²)/σ_ring`）→ 0.81
2. 线性增益标定（`(target-r)*2.4`）→ 0.81
3. K 值调 0.55 / 0.68 → 无改善
4. `--layer-sigma` 调 0.6/0.8 → 更差

### 真根因
自测脚本里 mask 是**手写实心矩形**：
```python
m = np.zeros((720,1280), bool); m[10:140, 930:1260] = True   # ❌ 42900 px
```
而真实水印 mask 是 `mask_720p_wide.png` 的**稀疏笔画形状 = 17743 px**（只有矩形的 41%）。
实心矩形把 mask 内大片 LaMA 已正常重绘纹理的**空白区**也算进去了 → σ 被稀释。

### 换正确口径后的真相（同一成片）
| 口径 | LaMa 无补 | 补纹理后 |
| --- | --- | --- |
| ❌ 实心矩形 42900px | 0.53 | 0.59 |
| ✅ 稀疏 mask 17743px | **0.60** | **1.11** ✅ |

**→ 固定 `--strength 1.3` 一直就是最优解（median 1.11），我的自适应改造全是负优化。**

### 铁律
1. **测纹理 σ 比必须用与修复一致的那张稀疏 mask PNG**，绝不手写矩形。
2. **「指标说不好」之前先怀疑尺子**（同手册坑 23-26 的主题；这是补纹理版）。
3. **改进反复不奏效时，回头验证基线测量是否可信**，而不是继续加复杂度。
   —— 简单方案（固定 strength）最终胜出。

  1648 帧, 54.933s, aac 双声道）—— 固定 `--strength 1.3` 版本。
- 中间产物：`weibo_demo1_clean.mp4`（仅 LaMa）、`weibo_demo1_final_v1_backup.mp4`。
- 对比图：`修复对比_2.0s_原片_仅LaMa_补纹理后.png`、`修复对比_28.0s_...png`（三联）。

- 纹理 σ 比：LaMa 后 median **0.60** → 补后 median **1.11 / mean 1.07**。

## 第二轮：用户仍反馈"明显痕迹" → 找到真凶（低频结构 + 颗粒闪烁）

### 诊断（两个被漏掉的痕迹类型）
1. **B 类·低频结构性痕迹（坑 38）**：场景里横穿水印区的条带（河岸/地平线）
   在修复区**断裂/变模糊光斑/凭空发明亮斑**，实测低频差达 ±40。
   - 补高频颗粒对此**完全无效**（40.74→40.42）。
   - **"mask vs 环低频差"是坏指标**：平移到无水印区读数一样大（max 79.8）——
     量的是场景自然梯度。诊断低频痕迹**只能目视最差帧**。
2. **C 类·颗粒时间闪烁（坑 39）**：texture_fix 的平铺块位置逐帧重随机
   → 静态场景颗粒图案每帧跳变。实测静态段 mask 区相邻帧差 p90=3.4（地板 0.2）。
   - 单帧指标完全测不出；且闪烁脚本曾把指标算在 clean 流上（读错文件），
     "改了参数数字纹丝不动"先查测的是哪个文件。

### 解法（都进了 texture_fix.py v0.2.5）
- `--lf-mode rowinterp`：低频用 bbox 左右无水印区**逐行线性插值**替换
  （条带天然延续、永不复制物体），高频保留 LaMa 细节。锚点在 bbox 外
  （x-38..x-4 与 x+w+4..x+w+20），LaMa 成片在这些区域=原片。
- 颗粒**每帧用相同种子重建 rng**（块位置全片固定，内容跟场景）：
  闪烁 p90 3.4→**0.98**、mean 0.87→**0.35**、max 7.3→**2.7**。

### 否决方案存档
- `scripts/patch_fill.py`（左移拷贝+seamlessClone Poisson）：条带场景完美，
  但复杂场景**复制物体**（紫水晶/栏杆线）。且 seamlessClone 的 center 必须
  用 **mask 外接矩形中心**（不是 PNG 几何中心，否则错位 10+px 留鬼影），
  mask 边界一圈是 Dirichlet 不被替换。脚本保留备用。
