### 新增判据：水印笔画模板（补 verify 三项的盲区）

verify 三项看不见**修复区内部**。用「mask 内 >150 像素数」数残留会骗人

### 其他踩坑

- **单帧极值不可信**：单看原片 107.0s 那帧报残白 2,840，看着像没修好；
  19 帧取中值只有 599 —— 那帧是亮内容扫过的边缘情况。**残留一律多帧取样取中值。**
- **逐帧排布能定位问题段**：帧 0-110 干净、115-190 有残白（494~2757）→ 只针对那几段加料。
- **`texture_fix.py` 没有 `--start` 参数**（不是打样脚本），传了会报 unrecognized arguments。
- **负索引坑（自建分析脚本时）**：`Y-PAD = 40-60 = -20` 会让 `arr[ry:ry+rh]` 切片为空，
  报 `cannot reshape array of size 0`。取 ROI 一律 `max(0, X-PAD)`。
- 磁盘 98% 满（剩 11GB）时全片渲染仍够用（成片 ~250MB），但要先清打样临时产物。

## ★★★ 续：v1 全片验收失败 → v2「全卡片 mask」正解（本轮最大发现）

**v1 成片全片跑笔画模板复核：降幅只有 83%，80/145 采样点有残留（最重 8415px 全亮）。**
根因：这片是**高动态舞台/演出片**，水印背后是**大面积移动白色内容**（舞台灯、白色道具）。
LaMa 在亮背景下把旁边的亮内容**延续**进 mask 笔画位 → 不是去掉水印，是重绘成亮块。

**亮度相关性（决定性证据）**：
| 分组 | 原片水印区左锚点（真实内容）亮度中值 |
|---|---|
| 干净点 65 个 | **17**（暗背景）|
| 重点 23 个 | **110**（亮背景）|

### 探索过的 7 条路（全部实测）

| 方案 | 结果 | 结论 |
|---|---|---|
| ① 时域中值（同位置前后帧中值） | 降幅 0% | ❌ 水印固定但背景在动（环区 std 53 vs 笔画 std 10），同位置中值仍是"水印+背景"混合 |
| ② alpha 反解（obs=αW+(1−α)B） | 降幅 16% | ❌ 拟合出 α=0.536/W=242 可信（obs=0.464·bg+129.9, n=66），但**文字笔画是不透明白**，反解去不掉 |
| ③ 膨胀 mask + TELEA inpaint | 66.5% | ❌ |
| ④ 全卡片+rowinterp | 48% | ❌ rowinterp 把卡片整宽用远锚点拉平，破坏真实内容 |
| ⑤ 两阶段 LaMa（卡片→稀疏） | 72.3% | ≈ 单卡片 |
| **⑥ 全卡片 mask + LaMa** | **72~76%** | ✅ **最优** |
| ⑦ 窄带膨胀 dil0/2/4 | 73% | ≈ 无差 |

### ★ 为什么「全卡片 mask」优于稀疏 mask（与原结论相反，但这次是对的）

关键在**测什么**。稀疏 mask 的"降幅 83%"是靠 rowinterp **把区域压暗**换来的
（所以有平滑雾面），而全卡片 mask 是 **LaMa 从卡片外真实背景重建**：
- **区max 从原片 251 → 242**（不发明亮块）
- **边界梯度比 3.84 → 1.09**（水印卡片可见边界消失）
- 残留 **407**（t=84 亮段）vs 稀疏方案 1802

**⚠️ 修正上一条结论**：坑 41 说"别换成实心 mask，实测更差"——那是在**暗背景片**上的结论。
**亮背景/高动态片，全卡片 mask 反而更好。** 判据：先看原片水印区**外环亮度**，
环暗用稀疏、环亮用全卡片。**要按片定策略，不能一刀切。**

### 新增判据：边界梯度比 ★

```
比值 = mean(sobel(mask 边界带内 2px)) / mean(sobel(mask 外侧))
原片（水印卡片边界可见）：3.84
全卡片修复后：              1.09   ✅ 边界消失
判据：接近 1 = 无可见接缝；>2 = 有接缝
```

### 本轮其他教训

- **verify 三项 + 笔画模板都还不够**：笔画模板只测"亮度降幅"，
  **看不见"降幅是不是靠压暗换来的"**。要看**区max变化**（是否发明亮块）+ **边界梯度比**。

  默认阈值下报 57400px + 触边告警；215 下干净输出 27393px + 探索通过。

### ★★ 新踩坑：亮背景下「残留/降幅」判据全部失效，要用**相对背景口径**

用标准口径跑，A/B 都报「降幅 15%、残留 4824（全模板位）」——**看着像完全没修**，
实际是**尺子坏了**：本片背景本就 203，`>150` 计数把背景全算成残留。

**正确口径**（背景亮时）：
```
判据 = 模板位均值 − mask内背景参照(mask内非模板像素)均值
原片 +25.9  →  成片 +1.5   降幅 94%  ✅
```
> **通用教训：残留判据必须相对背景。** 暗背景片用 `>100/>150` 绝对计数没问题；
> 亮背景片一律改成「模板位 − 邻近背景」的差值。写判据前先看背景亮度量级。
