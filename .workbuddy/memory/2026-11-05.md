### 新增脚本（6 个）

### 契约
- 脚本 CLI：`--input/--mask/--out/--bbox "x y w h"/--device`；mask 是 **bbox 局部尺寸** PNG（白=修复区）
- 退出码：**3 = 定位置信度不足 → 转人工，不重试**（pipeline 侧 `LOCATE_LOW_CONFIDENCE`）
- `build_mask` 打完打 `BBOX_RESULT: x y w h`，**pipeline 解析回填 ctx**（后续 lama/verify/修复轮全靠它）
- 决策树：`clean` / `needs_texture`(σ<0.8) / `needs_rowinterp`(Laplacian>1.5) / `needs_review`；修复轮跑完**复验**，两轮都不绿时交付**评分更好**的那份（`_score()`）

### ★★ 自动定位的四道判据（每条都对应真实失败案例）
1. **恒亮度** min 投影>225：纯白水印（卡片）可达 246 ✅；**半透明水印（微博视频号 logo）最高只有 217 ❌ 漏**
2. **值高+低波动** `score = 时域p90 − 2×时域std`：能抓半透明水印 ✅；但**舞台背景巨块 506520px** 抬高相对分数挤掉真水印 ❌ → **两通道并行跑取更可信的**
3. **位置恒定性** 区内std÷同高度周边带std < 1.05：水印 0.70~0.80 vs 人像高光 0.91~1.58 ✅（阈值不能更紧，0.80 会滤掉水印次要块）
4. **水平块簇**：只看水平相邻、**不要求 y 重叠**（微博水印两行 y 完全不重叠，要求重叠会切掉右侧 90px）；单块 >8000px 拒绝

### ★★★ 三个致命失效点（都实测踩过）
1. **片尾黑场毁定位**：54s 片片尾 6 帧均亮 1.3~2.5 → 时域分位数拉到 0 → 水印特征消失 → 定位全败。→ **抽帧后剔除暗帧（均亮<20）**
2. **触边 ≠ 被切**：水印在角落必然贴边 → 只有「该方向还能扩」才告警；**扩窗只做一次**（否则横跨窗口时一路扩到边缘→死循环→转人工）；**扩窗后必须重算 mask**（否则坐标错位）
3. **精修阈值不能自适应**：扩窗后混入背景高光，自适应阈值漂移 → mask 从 5000px 涨到 114699px → 绝对通道用全局固定阈值

### ★ 闪烁判据换口径
原用「修复区帧间差 ÷ **原片水印区地板**」，但原片水印区是静止叠加层（地板仅 0.064），0.3 的噪声除以 0.064 = 4.8 倍**假警报**。→ 改成 **÷ 同帧环带帧间差**（环带是同一画面真实运动量），环带静止时退回绝对值（上限 1.0）。

## OSS 开通落点（问答结论，未改代码）

`cloud_web/.env` 当前 **4 个 OSS 值全空**：`OSS_ENDPOINT` / `OSS_BUCKET` /
`OSS_ACCESS_KEY_ID` / `OSS_ACCESS_KEY_SECRET`（不只是 AK/SK；ENDPOINT 空会静默回落到
`oss-cn-hangzhou.aliyuncs.com`）。要创建的 3 样东西：
① oss.console.aliyun.com → Bucket 列表 → 创建 Bucket（**私有读写**，标准存储，与 ECS 同地域）；
② ram.console.aliyun.com → 用户 → 只勾「OpenAPI 调用访问」建 RAM 子账号拿 AK/SK
（**别用主账号 AK**），授权最小策略 GetObject/PutObject/DeleteObject 限定到该 bucket 的
`uploads/*` `results/*`；③ 该 Bucket 内配 **CORS**（来源是站点域名，方法 POST/GET/HEAD/PUT）
+ 生命周期（前缀 uploads/ results/，1 天兜底，对齐 `OSS_RETENTION_HOURS=24`）。

★★ **项目特有坑**：`oss.build_post_policy` 把 `https://{bucket}.{endpoint}` 直接当 `host`
返回给浏览器做 XHR FormData 直传 → `OSS_ENDPOINT` **必须是公网 endpoint**，
绝不能填 `oss-cn-xxx-internal.aliyuncs.com`（那是给 ECS 内网用的），否则浏览器上传必失败；
且未配 CORS 时后端签发仍成功、只有浏览器端被拦，排错容易误判成签名问题。
Bucket 保持私有即可：原片/成片全靠 15 分钟签名的 POST policy 与 GET/PUT URL。
