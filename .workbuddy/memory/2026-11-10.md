## 竞品收费模式调研（为无痕匠商业化方案校准）

背景：用户要求调研同类系统收费模式。对照 `docs/product/商业化方案.md`（¥49/月、¥365/年、加购 0.6 元/分钟、免费 3×30s、签到 +1/天月封顶 10）。

### 四类收费模式（2026-11 搜索口径，美元按 7.2 折算）

1. **桌面订阅/买断**：HitPaw 国内 ¥28/月、¥138/年、128 买断；海外 $15.99/月、$49.99/年（≈¥115/¥30 折算）。免费版导出加自家水印。买断制在萎缩（Inpaint $19.99 终身、Apowersoft $39 终身是老一代）。
2. **国内在线工具**（水印云 ¥48/月、¥108/年、三年 188；酷雀 ¥19/月、¥158/年）：
   - 双层体系=会员不限次主流功能 + AI 高级功能耗"永久点数"（送点数+单独充值，点数不过期）
   - 免费版带自家水印/每日 3-5 次限制
   - 裂变获客标配：邀 3/6/10 人得试用次数、朋友圈集赞换会员
   - 单设备在线限制（防共享账号）
3. **海外在线 AI（积分=秒）**：Wipe AI $7.99/月=300 credits（1 credit=1s）；ailab VWR Basic $9.99=400cr / Pro $29=1600cr / Max $49=3000cr，存储按档 7/30/90 天；AniEraser(Media.io) credits 包 $14.99/100 起（2 年有效）+ $27.99/月 600cr；LinoCut 100 免费 credits/天。共同点：**按秒透明计费 + 最低起步（3~5s）+ credit 大都不过期**。
4. **API 按量**：muapi 通用档 $0.065/次（5s 起）+ $0.013/s（≈¥5.6/分钟）、LaMa 档 $0.025+$0.005/s；wavespeed $0.05/5s（≈¥4.3/分钟，3s 起步）；国内聚合"视频去水印"API 0.02~0.1 元/次（多为链接解析非 AI 修复）。

### 对无痕匠的关键结论

- ¥49/月 = 国内最高档（超水印云 48）但低于海外最低档（Wipe AI 58）→ 定价本质是"国内价格、海外品质"卡位，验收报告差异化必须显性营销，否则打不过水印云 9 元/月折算年费。A/B ¥39 vs ¥49 方向正确。
- 免费层"限时长不加水印"在竞品中稀缺（只有链接解析类免费无水印），与"无痕"品牌一致 ✅。
- 超额加购 0.6 元/分钟 vs 海外 API 零售 4~6 元/分钟：成本 0.24 的定价即使上探也有空间，现价毛利 60% 合理。
- Phase 2 API/MCP 定价锚点：**0.5~1.5 元/分钟**（比海外便宜 4~8 倍、毛利 50-75%），采用"按秒计费 + 5s 起步价"行业惯例。
- 行业防漏惯例与我们一致：500MB 文件上限、单条 ≤10min、云端存储 7/30/90 天分层（我们 OSS 3 天在下限之下，作隐私卖点）。
- 建议补两件事：① 签到体系加**邀请裂变奖励**（行业标配，我们缺钩子）；② 考虑加**半年档**（水印云 98/半年 是走量挡位）。
