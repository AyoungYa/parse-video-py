# 2026-11-12

## 与大厂（阿里/字节/腾讯）去水印能力的对比结论

用户问「对比 AI 大模型平台，我们的优势在哪」。查证后的关键事实：

### 一、C 端大厂的「去水印」= 去自家水印，不是擦别人的水印

- 通义万相会员权益「去除图片和视频**品牌水印**」（导出不带通义水印），标准会员 47 元/月、高级 72 元/月；API Wan3.0-Video 480P 0.3 / 720P 0.6 / 1080P 1.2 元每秒（1080p ≈ 72 元/分钟）。
- 即梦 69/199/499 元/月，「基础会员可去水印」同理；可灵 66/266/666 元/月「高品质模式会员去水印」同理。
- 剪映消除笔：真能擦画面水印，会员约 39 元/月、198 元/年，支持动态漂浮水印自动识别——但它是编辑器工具，需手动上传框选。
- 万相 2.7 有交互式框选编辑（通用 inpainting），阿里云 ICE 也有擦除类能力。
- ★ 结构性判断：字节=抖音东家，不可能做「一键去抖音角标」的 C 端产品；平台方去自家角标等于自毁。

### 二、云侧要正视：腾讯云是真能力（不能说「我们效果比大厂好」）

- 腾讯云 **MPS 智能擦除**：`AiAnalysisTask` + `Definition=24`，支持十多种常见 Logo 自动识别擦除、定制训练（另收费）、模糊/马赛克/无痕三种效果；同一接口可做「去字幕+翻译+配音」出海组合。另有 VOD `RemoveWatermark` 接口。
- 腾讯云 **WAND-EraseVibe+**：官方口径「零伪影、帧间一致、日处理 10 万分钟、覆盖 80%+ 头部短剧客户」——**帧间一致性他们已经在做**，且面向 B 端短剧出海/平台方。
- 结论：单点算法/模型能力上我们**不占优**，营销口径绝不能讲「效果比大厂好」。

### 三、我们的四层优势（写进定位口径）

1. **场景空白是结构性的**：大厂是平台方（不能去自家角标）+ 受《AI 生成合成内容标识办法》约束（必须给合成内容加标，不会高调卖去水印）；小团队在夹缝里做「用户自有素材修复」。★ 边界必须守住：定位是自有素材，不是帮人盗用。
2. **他们是能力（API/编辑器），我们是产品闭环**：贴链接→自动定位→修复→验收→交付成片+报告；云 API 要接 SDK、轮询、备案资质，自媒体用户不会用。
3. **验收报告连大厂都没有**：腾讯云 `AiQualityControlTask` 是转码画质检测（抖动/模糊/噪点），**不是修复效果验收**。这是全行业（含大厂）唯一空白，也是我们唯一能称「能力差异」而非「体验差异」的点。
4. **成本结构决定价格带归属**：大厂用旗舰生成模型做修复算不过账（通义 1080p 72 元/分钟 vs 我们 0.24 元/分钟），所以它们只按分钟卖给 B 端，不做 ¥49/月 C 端。

### 四、风险与护城河方向

- 单点算法不是护城河。腾讯云 MPS 能力被白牌商包装成 C 端产品是现实威胁（套壳者比大厂更难缠，因为便宜）。
- 护城河要建在三处：**语料+验收阈值校准（数据飞轮）**、**报告带来的信任溢价**、**垂直场景迭代速度**——大厂看不上、套壳商跟不上。
- 一句话定位：大厂卖铲子（模型/API），我们卖挖好的井（成片）+ 水质检测报告（验收）。

## 「竞品没报告是不是因为不需要」自我质疑结论

需求侧验证（黑猫投诉 2026-03「无痕去水印」App 98 元案、海外 App Store 差评、HitPaw 退款纠纷）：
「付费后效果差、不退款」纠纷大量存在——用户在意效果但**无客观依据主张权利**，只能去投诉平台。

但也要承认"不需要"的一半：

- 大众低风险场景（角落 Logo 发朋友圈）扫一眼就够，报告属过度设计；信任只在出问题时变现，事前感知弱。
- ★ 竞品不做报告一半是**理性法务策略**：报告=自立标准=给用户递刀（有报告可主张违约），免责声明保护的是"概不退款"的商业模式。
- ★ 我们的正确姿势：报告**对内>对外**（全绿才交付/自动重跑/降退款率，没人看也回本）；对外只承诺「不达标不扣费」，**不承诺「全绿=完美无痕」**；大众流量场景报告后台静默跑。
- ★ 上线后 A/B 归因：看**退款率/复购率**差（不是转化率）；若退款率没降→"报告作为信任机制"假设失败，退回内部质量闸门用法，产品不受损。
