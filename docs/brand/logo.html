无痕匠 · 品牌标识规范

标识 = 「帧 · 擦」标：圆角方块（源自视频画幅，延续印章基因）内反白一个播放键（视频处理）， 右上角一道弧形擦口——水印最常见的角落被干干净净擦掉，原位留一颗四角星芒（擦净焕新）。 三个内形全部以 mask 挖空实现，不依赖第二色，任何背景色都成立。

05 · 使用规则

  • 净空：标识四周保留 ≥ 印宽 1/4 的空白，不与文字、图片贴边。
  • 最小尺寸：图形标 16px、组合标高 40px；更小场合只用图形标。
  • 不改色、不加描边、不拉伸、不换字体；图形标不得旋转（擦口必须朝右上）。
  • 禁止把印底换成照片 / 渐变；深浅底用对应版本而非透明叠加。
  • 应用内统一走 <BrandLogo> 组件（mask 挖空，自动适配背景）。

06 · 资产与再生成

  • 应用内组件：frontend/src/components/BrandLogo.vue（顶栏 / 登录页已接入）。
  • 静态文件：frontend/public/（favicon.svg / favicon.png / apple-touch-icon.png / logo-mark*.svg / logo*.svg）。
  • 整套静态资产一键再生成：docs/brand/gen_assets.py（需 playwright）；字标轮廓数据见 docs/brand/_lockup_data.json。
