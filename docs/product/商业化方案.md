# 去水印功能商业化方案（基调版）

> 2026-11-04 定稿。本文件是商业化基调的唯一权威来源，后续 MVP 开发以此为准。
> 调研背景见同日项目记忆日志；竞品与法律调研结论已内化到本文。

## 一、产品定位

**一句话**：用户上传自己的视频 → AI 无痕去水印 → 附自动质量验收报告的网页工具。

- **只做本地素材处理**，不做平台链接解析/下载/绕查重（法律红线，杭州等多地法院已有判例）。
- **差异化核心卖点**：效果可验收——每单附「残留/纹理/闪烁」三项指标报告，全绿才交付。
- 目标用户分层：
  - C 端：自媒体二创、素材整理（走量，签到积分养留存）
  - B 端：MCN / 电商 / 有授权素材的公司（包月主力付费来源）

## 二、阶段路线

### Phase 1：网页版 MVP（快速上线）

**范围（做）**：
1. 上传视频（≤ 一定时长/大小，见付费体系）
2. 自动定位水印（时域 min 投影 + 连通块分析，固化现有决策树）
3. 交互确认/微调 mask（复用 wm-studio 的调参台交互）
4. 处理 → 预览前后对比 → 下载成片 + 质量验收报告页

**明确不做（Phase 1 非目标）**：
- 不做桌面客户端、不做小程序（第二优先级验证后再说）
- 不做多用户团队协作、不做 API
- 不做 ProPainter 引擎（NTU S-Lab 许可证禁商用；剧烈运动场景直接标注"暂不支持"）

**技术复用映射**（现有代码 → 产品模块）：

| 现有模块 | 产品化用途 | 改造量 |
|---------|-----------|--------|
| `wm_studio/`（调参台） | 用户交互页骨架 | 小：去调参术语、简化为三步流程 |
| `build_mask`（min>100 柔边逻辑） | 自动 mask 定位 | 中：决策树自动化、失败降级提示 |
| `lama_apply_maskonly.py` | 修复引擎（LaMa, Apache 2.0 ✅） | 小 |
| `verify.py` + 四层残留检测 | 验收报告生成 | 中：输出为用户可读的 HTML 报告 |
| `texture_fix.py` / `rowfill.py` | 按背景分流的痕迹修复 | 小 |
| 内存分流抽帧（BATCH_DECODE_LIMIT） | 服务端大文件处理 | 无（直接复用） |

**部署**（详细选型与成本模型见 `成本与选型.md`，架构见 `算力部署方案.md`）：
- Web/API/队列/交付页 → 阿里云轻量 2核4G（¥379/年，200M 不限流量，**需已备案**）
- 渲染算力 → **本地优先**：开发期 Mac（MPS 现成可用）→ 正式期自建单卡 4090 PC
- **不租云 GPU**：自建月成本 934 元、日产能是云 T4 的 4 倍，等效算力口径 3~5 个月回本；
  云 GPU 仅作补峰/兜底，触发门槛见 `算力部署方案.md` §6
- ⚠️ ⚠️ 硬约束：**家宽不能对外提供 Web 服务和备案**，所以本地只做 worker，Web 必须上云
- 队列串行处理即可（720P 小 ROI MPS 实测 0.2s/帧，单机吞吐足够冷启动）

### Phase 2：MCP Server（供各 Agent 使用）

上线时机：网页版跑通、计费体系稳定后。

**工具设计（初稿）**：
- `remove_watermark(file_path_or_url, mask_hint?)` → 提交任务，返回 task_id
- `get_task_status(task_id)` → 轮询进度
- `get_task_result(task_id)` → 成片 URL + 验收指标 JSON
- `estimate_cost(file)` → 预估积分消耗（Agent 可先算再决定）

**鉴权与计费**：API key 绑定账号，与网页版共用同一套积分/订阅余额。
**Agent 场景叙事**（也是获客话术）：内容生产 Agent 的素材清理环节、
自动化剪辑管线的一站工具。

### Phase 3（暂不展开）：按次充值 / 批量 API / B 端定制

## 三、付费体系（基调确认）

> ★ 本节数值已按 `成本与选型.md` 的成本模型校准（2026-11-04）。基准成本 **0.24 元/视频分钟**。

### 1. 免费试用

- 新用户：**3 条、单条 ≤ 30s** 的处理额度（实测成本 **0.35 元/人**）
- 试用导出**不加自家水印**（差异化：竞品免费版都加水印，我们靠限制时长控成本，
  保持"无痕"品牌一致性）
- 试用也出验收报告（让用户第一天就体验到卖点）
- **有意放大试用**：单用户成本仅 0.35 元，转化 8 个包月用户即回本 → 真正的风险不是被薅，
  而是转化不够。宁可给足体验，别抠额度。

### 2. 每日签到送积分

- 签到得 N 积分，积分 = 处理额度的通用货币
- 积分规则（已按成本校准）：

| 动作 | 积分 |
|------|------|
| 每日签到 | **+1** |
| 连续 7 天额外 | +5 |
| **月累计上限** | **10 分** ← 关键防漏 |
| 单条 < 30s 视频 | -1 |
| 单条 30s~5min 视频 | -3 |
| 单条 > 5min | 包月用户专属 |

- ⚠️ **原设计「+2/天、不封顶」是成本黑洞**：等于每天白送 1 分钟处理量 = **7.07 元/月/人**，
  1000 个只签到不付费的用户就是 7,000 元/月纯烧钱（比 GPU 包月贵 4 倍）。
  改为 +1/天 + 月累计封顶 10 分后，暴露降到 3.5 元/月。
- 积分的作用是**养成打开习惯**，不是送免费额度。
- 积分月度清零（防止囤积、保证包月吸引力）
- 防滥用：同设备/同支付账号识别，签到需登录

### 3. 包月订阅

- **定价锚点**：竞品 ¥30~70/月（HitPaw/水印云档）；
  本产品凭验收报告支撑溢价，**建议 ¥49/月、¥365/年**（¥39 方案毛利垫太薄，见下）
- 包月权益：不限条数 + **公平使用上限 100 分钟/月**（原拟 300 分钟会亏钱）、
  单条 ≤ 30min、**每月赠 2 条 ≤5min 的 4K 额度**、优先队列、批量上传
- **超出后加购**：¥0.6/分钟（成本 0.24，毛利 60%）
- 逾期未续费 → 回落为签到积分用户（保留账号和数据）

**为什么是 100 分钟而不是 300 分钟**：¥49 包月的毛利随用量塌陷——20 分钟典型用户毛利率
90%，100 分钟掉到 51%，**300 分钟直接 -45%（每用户倒亏 22 元）**。100 分钟既保住 51% 毛利，
又能覆盖 95% 以上的真实用户用量（待上线 4 周后用真实 P90 校验）。

**为什么 4K 不能算进包月无限量**：4K 单位成本是 1080P 的 **4.5 倍**（1.07 vs 0.24 元/分钟），
30 分钟 4K 一条就 ¥32，两条吃光包月。"4K 支持"作为卖点保留，但用赠额 + 超出计费兜住。

### 4. 成本控制闸门（所有付费档共用）

- **主闸门是「总时长」，不是「分辨率」**：免费档 ≤ 30s/条、免费档每日总量上限、
  包月 100min/月硬闸门。原因见下。
- 文件大小上限（如 500MB）+ 并发队列限流
- 处理时长超阈值自动拒绝并提示（不要"降级处理"，降级会破坏"全绿交付"的品牌承诺）

> ⚠️ **别用「降分辨率」当成本闸门**。LaMa 只处理 ROI 裁剪块，720P 和 1080P 的处理帧数和
> ROI 绝对尺寸基本相同 → **降分辨率几乎不省 GPU 成本**，只省一点流量，还白送一个差评点。
> 想省钱就砍时长。（模型验证见 `成本与选型.md` 第六节第 6 条）

## 四、合规底线（不可退让）

1. 用户协议明示"仅限自有版权或已获授权素材"
2. 不做平台定向水印的批量方案营销话术
3. 素材处理完即删（承诺不留存，作为隐私卖点）
4. 商用引擎仅用 Apache 2.0 许可的模型（LaMa ✅）；**ProPainter 永不进商用版**

## 五、北极星指标与验证门槛

- 北极星：**每周成功交付（验收全绿）的视频条数**
- 上线 4 周验证：签到次留 ≥ 25%、免费→包月转化 ≥ 3%、验收全绿率 ≥ 90%
- 全绿率 < 90% 说明自动定位/分流决策树还不够稳，先修管线再拉新
