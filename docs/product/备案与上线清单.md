## 二、Step 1 · 域名实名认证（必须你本人操作）

路径：阿里云控制台 → 域名 → 域名列表 → `wuhenjiang.com` → 域名管理 → **实名认证**

**个人认证（本次采用）需要准备：**

| 材料 | 要求 |
|------|------|
| 身份证 | 正反面清晰照片，**四角完整、无反光、无遮挡**（姓名/身份证号/有效期必须可辨认） |
| 手机号 | 阿里云账号绑定的手机（用于接收核验短信，需能接收验证码） |
| 手写签名 | 白纸黑字写「阿里云」+ 注册人姓名，**签名要端正**（与证件姓名一致） |

**审核周期**：通常 **2~24 小时**（工作日更快）。审核结果短信通知。

> ⚠️ **个人主体的已知限制**（不影响当前阶段，但要提前知道）：
> - 微信支付商户号**需要企业主体**（营业执照），个人做不了 → 付费功能要等 M4 阶段处理，
>   或届时补一个企业主体（个体工商户执照也行）。
> - 无法开具增值税专用发票（只能开个人普通发票）。
> - ICP 备案**个人主体可以备案**，网站性质要选「个人」，
>   ⚠️ **个人备案的网站不能有论坛/商城/支付等经营性功能**——
>   我们的「上传视频→处理→下载」属于工具类，通常可过；
>   但**接入微信支付后可能被要求改为企业备案**。
>   → 建议：备案先用个人跑通，等接支付时同步升级为企业备案（需重新提交，会再花 10~20 天）。

**审核不通过最常见的原因**：照片反光/裁切、签名与姓名不一致、手写签名太潦草。

## 三、Step 2 · 解析与备案前置配置

实名认证通过、serverHold 解除后：

1. **设置 NS 委派**（阿里云备案强制要求 NS 指向阿里云）
   - 控制台 → 域名 → DNS 修改 → 修改 DNS 服务器
   - 阿里云给的默认 NS 一般是：`ns1.dns.com` / `ns2.dns.com`（以控制台实际显示为准）
   - ⚠️ 当前 whois 显示的是 `DNS19.HICHINA.COM`，这是**注册商默认 NS**，
     不是 DNS 解析记录。备案要求把 NS **委派**到阿里云的解析服务器。

2. **加一条 A 记录指向服务器公网 IP**
   - 主机记录 `www`，记录类型 `A`，记录值 = 服务器公网 IP
   - 主机记录 `@`，同上（`wuhenjiang.com` 裸域名）
   - TTL 用默认值（10 分钟）

3. **关闭阿里云 CDN / 加速**（如果开了）——备案要求域名解析到接入商 IP

## 四、Step 3 · 提交 ICP 备案

路径：阿里云控制台 → 备案服务 → 备案管理 → **开始备案**

### 需要准备的信息

| 项 | 内容 | 备注 |
|----|------|------|
| 主体信息 | 姓名、身份证号、手机、邮箱、通信地址 | 与实名认证完全一致 |
| 网站信息 | 网站名称、服务内容、备注 | ⚠️ 见下方「网站名称怎么填」 |
| 域名 | `wuhenjiang.com` | 必须是已完成实名、状态正常的域名 |
| 服务器 | 阿里云轻量服务器实例（IP + 实例 ID） | 备案必须绑定一台阿里云服务器 |
| 前置审批 | **无**（不涉及新闻/出版/教育/医疗/金融） | ✅ 好消息，这类不用前置批文 |

### ★ 网站名称怎么填（最容易被打回的一步）

「无痕匠」三个字 **可能** 被驳回，原因是含「匠」无类目词，审核方会要求补「工具/平台/软件」等类目词。

**建议写法**（按风险从低到高）：
- `无痕匠工具` ← 推荐，工具类，通用
- `无痕匠软件`
- `无痕匠视频处理` ← 更具体，但「视频」可能触发额外审核

**网站服务内容**选「其他」或「软件工具」，简介写：
> 「无痕匠」是一站式视频处理工具，提供视频去水印、水印清除等影像编辑功能。

⚠️ **不要写「去水印」三个字进网站名称**——容易被判定为「涉及侵权/内容违规」，驳回率高。
名称里只留「无痕匠 + 类目词」，功能描述里再写具体能力。

### 备案时长

- 阿里云初审：**1~2 个工作日**
-管局审核：**7~20 个自然日**（各省不同，通常 10~15 天）
- 期间会收到**短信核验**（工信部要求，24 小时内回复验证码，否则退回）—— ⚠️ 别漏！

**期间可以做**：开发、写代码、用本地/测试环境联调。**不能做**：正式对外提供服务。

## 五、Step 4 · 备案通过后的三件事

### 1. HTTPS 证书

- 阿里云控制台 → SSL 证书 → 免费证书 → DV 单域名 → 域名填 `wuhenjiang.com` + `www.wuhenjiang.com`
- 签发后下载 **Nginx 格式**，得到 `fullchain.pem` + `privkey.pem`
- 放到服务器 `cloud_web/deploy/certs/`（该目录已 gitignore）
- 解开 `cloud_web/deploy/nginx.conf` 里的 HTTPS 模板，把 80 端口改成 301 跳转

### 2. 生产配置

`cloud_web/.env`（生产机上）关键项：

```ini
DJANGO_SETTINGS_MODULE=config.settings.prod
DEBUG=0
ALLOWED_HOSTS=wuhenjiang.com,www.wuhenjiang.com
CSRF_TRUSTED_ORIGINS=https://wuhenjiang.com,https://www.wuhenjiang.com
CORS_ALLOWED_ORIGINS=https://wuhenjiang.com
```

### 3. 微信支付商户号（依赖备案）

备案通过后**立刻**申请（3~10 个工作日）：
- ⚠️ **个人主体做不了微信支付**，需要企业/个体工商户主体。
  当前个人备案 → 付费功能（M4）要么延后，要么同步升级为企业备案。
- 需要：营业执照、法人身份证、结算银行账户、网站域名（已备案）、ICP 备案号

## 八、常见驳回原因速查

| 驳回原因 | 怎么改 |
|----------|--------|
| 网站名称不符合规范 | 名称加类目词：「无痕匠工具」 |
| 域名未实名 / 状态异常 | 等 serverHold 解除再提交 |
| 网站名称涉及「去水印/破解/下载」等敏感词 | 名称改成中性词，功能描述里再写 |
| 服务内容与备案性质不符 | 选「工具/软件」而非「论坛/商城」 |
| 通信地址不详细 | 写到门牌号，与身份证一致 |
| 主体信息与实名认证不一致 | 逐字核对，手机号要用同一个 |
| 域名未指向接入商 IP | 先设 A 记录再提交 |
| 忘记回复核验短信 | 备案被退回，重新提交 |
